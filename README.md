# Vue3-TS-Template_V2

## Vue3 + TS 模板-V2

```bash
npm create vite Vue3-TS-Template_V2 --template vue
```

## Project Setup

```sh
npm install
```

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
